# 数据来源与许可说明（成员 A）

## 1. 校区范围与参考信息
- 项目对象：东南大学四牌楼校区。
- 校区位置及官方介绍以东南大学公开校园介绍资料为参考。
- 本项目使用的初始抓取范围（bbox）仅为数据采集窗口，不代表经学校确认的法定校区边界。
- 采集范围内的道路可能因 OSM way 完整返回而延伸到 bbox 之外；是否裁剪应结合项目需求决定。

## 2. 空间数据来源
- 道路、道路节点及建筑轮廓：OpenStreetMap（OSM），通过 Overpass API 获取。
- 原始 Overpass 数据时间戳：2026-11-25T06:07:15Z。
- 道路保留 OSM way 标识；拓扑修复使用原始 way 的有序 node ID 序列。
- 本数据未声称覆盖校区内全部道路、建筑或设施，也未经过现场测绘。
- OSM 未提供的建筑高度保留为空值；重要设施点位仍需补充可靠来源并核验。

## 3. 许可与署名
OSM 数据依据 Open Database License 1.0（ODbL）提供。再分发或公开使用 OSM 数据库及其衍生数据库时，应遵守 ODbL 的署名及适用的相同方式共享要求。

- 地图署名：© OpenStreetMap contributors
- 版权与许可：https://www.openstreetmap.org/copyright
- 署名指南：https://osmfoundation.org/wiki/Licence/Attribution_Guidelines
- 许可 FAQ：https://osmfoundation.org/wiki/License/Licence_and_Legal_FAQ

本项目使用的是通过 Overpass API 获取的 OSM 矢量要素，不应将标准地图瓦片截图或瓦片缓存误认为本项目的矢量数据来源。

## 4. 数据来源标记
- `real`：来自所注明的真实数据源（本项目中主要为 OSM）。
- `estimated`：估算或推算值，不代表现场实测。
- `synthetic`：为测试或演示生成的模拟数据。

## 5. 已知限制与使用注意事项
1. OSM 数据可能不完整、存在滞后或标注错误。
2. 初始 bbox 不是官方校区边界；完整道路几何可能超出该范围。
3. 道路速度字段中的默认值不等于实测速度。
4. 单行属性、道路通行状态、门禁、施工、桥梁/地下通道及消防车辆通行权限均需进一步核验。
5. 共享 OSM node ID 可用于识别 OSM 数据中的拓扑连接，但不等同于现场确认的可通行连接。
6. 建筑高度缺失时为空值，不应自行解释为零层或无高度。
7. 重要设施点位、校园出入口和应急车辆通道应以学校官方资料或现场核查为准。

## 6. 拓扑处理说明
新版道路拓扑基于原始 OSM way 的有序 node ID 序列，仅在多个已选道路 way 共享的 OSM node ID 处进行切分，不以单纯的几何坐标相交推断连接。该处理改善数据结构的一致性，但不构成现场道路通行核验。
