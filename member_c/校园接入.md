# 九龙湖校区 · 成员 C 接入记录

本次选择李文正图书馆至文科 C 楼一带。地图使用 WGS84，经度在前。landmarks.geojson 可作为 B 的点图层。三处建筑代表点有公开位置来源，各点属性含来源链接和 OSM 编号。学校官网确认李文正图书馆位于九龙湖校区。[东南大学图书馆](https://lib.seu.edu.cn/list.php?fid=219)

地点数据署名 © OpenStreetMap contributors，按 [ODbL](https://www.openstreetmap.org/copyright) 使用。建筑输入中的小矩形是围绕代表点生成的展示框。六个路口和七条双向路组成合成演练路网；长度由端点间局部球面距离估算，15 km/h 是推演设定。地图展示时保留“演示道路、估算建筑轮廓”图例。雨强、排水、汇水倍率与地震影响名单均为情景假设；建筑与道路的关系仅供模型演示。

## 运行

在解压目录执行下列命令。原始 fixed_* 文件用于旧样例回归，九龙湖输入输出使用 jlh_ 前缀。

```
python hazard.py jlh_flood.input.json local-flood.json
python hazard.py jlh_earthquake.input.json local-quake.json
python -m unittest -v
```

A 可按 nodes.json 和校园输入样例内的 roads、buildings 提供实测资产，更换时同步更新 params 引用。B 可按 time_min 取帧，并分别绘制真实地标与情景资产。C 的独立适配入口为 SimulationProvider().simulate(scenario, roads, buildings)，见 simulation_provider.py。D 用同帧 road_id 加入路网，剔除 closed 后选路。版本冲突响应及 run_id 由 E 的 API 管理。正式后端入口见 backend.c_hazard.CProvider，按 docs/INTEGRATION_GUIDE.md 实现 scenarios() 和 replay(scenario)。在仓库根目录注入 create_app(data_directory=Path("member_c/jlh_campus"), simulation_provider=CProvider(Path("member_c/jlh_campus")))。单次 replay 发布最后一个与 step_min 对齐的快照；离线模块保留全部时间片。

从 JLH-N1 到 JLH-N3 的直达通道经 R1、R2。第 50 分钟 JLH-R2 积水 0.325 米，被标记 closed；可经 JLH-R1、R6、R4、R7 绕行（各路段均带 JLH- 前缀）。地震固定情景下 R2 同样封闭，R6 谨慎通行。各路段状态可在对应 output.json 内按时间和 ID 核对。
